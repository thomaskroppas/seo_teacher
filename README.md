# SEO-обучатель

Личный интерактивный курс по SEO на ~8 недель: от основ и выбора ниши — через покупку сайтов, техническое SEO, контент и линкбилдинг — до запуска страниц в ТОП-10 и масштабирования.

## Запуск

Сборка не нужна. Откройте `index.html` в браузере (или `python3 -m http.server` и http://localhost:8000). Прогресс хранится в `localStorage` браузера; перенос/резерв — в «⚙ → Экспорт».

## Что внутри

- **48 уроков в 8 модулях** (~65 000 слов теории): теория → практические задачи → квиз → карточки.
- **Интервальное повторение** карточек (Лейтнер: 1 → 3 → 7 → 16 → 35 дней), 385 карточек.
- **Квизы** (single / multi / верно-неверно / сценарии) с разбором ответов; варианты перемешиваются; **тренажёр** с режимом «работа над ошибками»; **экзамен** по каждому модулю (порог 75%).
- **48 кейсов с выбором**: ситуация → решение → последствия каждого варианта.
- **Инструменты**: оценка покупки сайта (окупаемость + риск-скоринг), ссылочный бюджет, прогноз трафика и дохода, анкор-план, кластеризатор, генератор ТЗ, ROI страницы.
- **Проекты**: ключи и позиции, журнал ссылок, бюджет, статусы.
- **10 чек-листов** (запуск, покупка сайта, аудит, on-page, ТЗ, донор, линкбилдинг, миграция, падение трафика, рутина), **словарь** (170+ терминов), поиск по курсу.

## Программа

| Нед. | Модуль |
|---|---|
| 1 | Фундамент: поиск, интент, факторы, санкции, инструменты, модели монетизации |
| 2 | Ниша и семантика |
| 3 | Покупка сайта и домена |
| 4 | Техническое SEO |
| 5 | Контент и on-page |
| 6 | Линкбилдинг |
| 7 | Запуск до ТОП-10 |
| 8 | Масштаб и профессионализм |

## Структура

```
index.html        точка входа
css/style.css     стили (светлая/тёмная тема)
js/               markdown.js (рендер), store.js (прогресс, SRS), app.js, views.js, tools.js
data/             module-1..8.js (контент), glossary.js, checklists.js
docs/CONTENT_SPEC.md   формат контента и учебный план
scripts/validate.js    проверка структуры контента: node scripts/validate.js
```

Чтобы добавить/изменить урок, правьте `data/module-N.js` по `docs/CONTENT_SPEC.md` и запустите валидатор.

## Важно

Контент написан без живой проверки источников: цены бирж, названия сервисов, правила площадок и политики поисковиков меняются — сверяйтесь с официальной документацией (ссылки есть в каждом уроке). Примеры сделок и кейсы иллюстративные.
