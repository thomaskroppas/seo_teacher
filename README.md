# SEO-обучатель

Личный интерактивный курс по SEO на ~8 недель: от основ и выбора ниши — через покупку сайтов, техническое SEO, контент и линкбилдинг — до запуска страниц в ТОП-10 и масштабирования.

## Запуск

Сборка не нужна. Откройте `index.html` в браузере (или `python3 -m http.server` и http://localhost:8000). Прогресс хранится в `localStorage` браузера; перенос/резерв — в «⚙ → Экспорт».

## Для кого

Для человека, который **никогда не работал с SEO и сайтами**: уверенно пользуется интернетом, играет в игры, сидит в соцсетях, но видел сайты только как посетитель. Язык простой, термины объясняются на аналогиях из игр и соцсетей, уроки короткие (20–40 минут).

## Что внутри

- **11 модулей, 79 коротких уроков** (~50 000 слов): теория → практическая задача → квиз → карточки. Темп — 1 урок в день, около 14–16 недель.
- **Сквозной проект «Мой первый сайт»**: домен .ru на reg.ru (≈ 200 ₽) + хостинг (≈ 300–500 ₽/мес) + WordPress, затем Search Console/Вебмастер, статьи, ссылки, мониторинг. Бюджет старта — до 1000 ₽. Позже — второй проект на .com для англоязычного рынка и покупка готовых сайтов.
- **Два рынка**: везде, где различаются инструменты и цены, есть врезки 🇷🇺 (Яндекс, reg.ru, рубли) и 🌐 (Google, Namecheap и т.п., доллары).
- **Интервальное повторение** карточек (1 → 3 → 7 → 16 → 35 дней), ~390 карточек.
- **Квизы** с разбором ответов (варианты перемешиваются), **тренажёр** с режимом «работа над ошибками», **экзамен** по каждому модулю (порог 75%), ~550 вопросов.
- **44 кейса с выбором**: ситуация → решение → последствия каждого варианта.
- **Инструменты**: бюджет старта, оценка покупки сайта, ссылочный бюджет, прогноз трафика и дохода, анкор-план, кластеризатор, генератор ТЗ, окупаемость страницы.
- **Проекты**: ключи и позиции, журнал ссылок, бюджет, статусы.
- **12 чек-листов** (в том числе «Мой первый сайт» и «Бюджет и безопасность старта»), **словарь** (239 терминов с аналогиями), поиск по курсу.

## Структура

```
index.html        точка входа
css/style.css     стили (светлая/тёмная тема)
js/               markdown.js (рендер), store.js (прогресс, SRS), app.js, views.js, tools.js
data/             module-1..11.js (контент), glossary.js, checklists.js
docs/CONTENT_SPEC.md   портрет ученика, формат контента и учебный план
archive/pro/           прежняя версия курса «для профи» (источник фактов, в приложении не используется)
scripts/validate.js    проверка структуры контента: node scripts/validate.js
```

Чтобы добавить/изменить урок, правьте `data/module-N.js` по `docs/CONTENT_SPEC.md` и запустите валидатор.

## Важно

Контент написан без живой проверки источников: цены бирж, названия сервисов, правила площадок и политики поисковиков меняются — сверяйтесь с официальной документацией (ссылки есть в каждом уроке). Примеры сделок и кейсы иллюстративные.
