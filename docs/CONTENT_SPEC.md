# Спецификация контента SEO-обучателя

Курс: 8 модулей × 6 уроков = 48 уроков (≈ 8 недель, 1 урок в день по ~60–120 минут вместе с практикой).
Каждый модуль — отдельный файл `data/module-N.js`. Язык — русский. Рынок — универсальный (Google — основной, Яндекс — отдельными врезками).

## Формат файла

```js
window.COURSE_MODULES = window.COURSE_MODULES || [];
window.COURSE_MODULES.push({
  id: "m1", num: 1, week: "Неделя 1",
  title: "Фундамент",
  subtitle: "одна строка",
  goal: "Что человек сможет после модуля (2–3 предложения)",
  lessons: [ /* ровно 6 */ {
    id: "m1-l1",
    title: "...",
    minutes: 90,                     // общая оценка (теория+практика+квиз)
    summary: "1–2 предложения: зачем этот урок",
    objectives: ["после урока вы сможете ...", "..."],   // 3–5
    theory: `markdown (см. ниже), 900–1600 слов`,
    practice: {
      intro: "1–2 предложения",
      tasks: [ // 2–4 задачи, РЕАЛЬНЫЕ действия в реальных инструментах
        { id: "m1-l1-t1", title: "...", minutes: 30,
          steps: ["конкретный шаг", "..."],        // 3–8 шагов
          deliverable: "что должно получиться (файл, таблица, скрин, вывод)",
          checklist: ["критерий самопроверки", "..."] }   // 2–5
      ]
    },
    quiz: [ // 7–9 вопросов, смесь типов
      { type: "single", q: "...", options: ["a","b","c","d"], answer: 2, explain: "почему верно и почему остальные нет" },
      { type: "multi",  q: "... (выберите все верные)", options: [...], answer: [0,2], explain: "..." },
      { type: "truefalse", q: "утверждение", answer: true, explain: "..." },
      { type: "scenario", q: "Ситуация: ... Что делать?", options: [...], answer: 1, explain: "..." }
    ],
    cards: [ { front: "термин/вопрос", back: "короткий точный ответ (1–3 предложения)" } ],  // 6–10
    resources: [ { title: "...", url: "https://...", note: "зачем" } ]   // 2–5, только реально существующие официальные/известные ссылки
  } ],
  scenarios: [ // ровно 6 «карточек с выбором» на модуль — мини-кейсы про принятие решения
    { id: "m1-s1", title: "...", situation: "2–5 предложений с цифрами/деталями",
      choices: [ { text: "...", verdict: "best"|"ok"|"bad", feedback: "почему; к чему приведёт" }, ... ] } // 3–4 варианта, ровно один best
  ],
  exam: [ /* 12 вопросов того же формата, что quiz, по всему модулю; id не нужен */ ]
});
```

Поля `answer` у `single`/`scenario` — индекс, у `multi` — массив индексов, у `truefalse` — boolean.
Правильные ответы должны быть **равномерно распределены** по позициям (не всегда вариант B).

## Markdown в `theory` (поддерживается мини-парсер)

`## Заголовок`, `### Подзаголовок`, абзацы, `- списки`, `1. нумерованные`, `**жирный**`, `*курсив*`, `` `код` ``,
`[текст](url)`, `---`, таблицы (`| a | b |` с строкой `|---|---|`), блоки-врезки (строки с `>`):
`> 💡 Совет …`, `> ⚠️ Риск …`, `> 📌 Запомнить …`, `> 🧪 Пример …`, `> 🇷🇺 Яндекс: …`.
Внутри template literal экранируйте обратные кавычки и `${`.

## Требования к качеству

- Это учебник для человека, который хочет **реально выводить сайты в ТОП-10, покупать сайты/домены и строить ссылки**. Не вода: конкретные пороги, формулы, чек-листы, шаблоны писем/ТЗ, примеры запросов, примеры цифр.
- Объясняйте «почему», затем «как», затем «как проверить». От простого к сложному, опирайтесь на предыдущие уроки (давайте отсылки «см. урок 2.3»).
- Актуальность на 2025–2026: AI Overviews и AI-поиск, INP вместо FID, helpful content, spam policies Google (scaled content abuse, expired domain abuse, site reputation abuse, link spam), core updates, IndexNow, E-E-A-T.
- Никаких выдуманных кейсов «как факта» и выдуманной статистики. Иллюстративные примеры помечайте «🧪 Пример (иллюстративный)». Если цифра — ориентир/эвристика, так и пишите («ориентир, не закон»).
- Честность: SEO — вероятностная игра; где мнения экспертов расходятся — скажите. Обозначайте риски серых методов (PBN, массовые покупные ссылки, expired domains) и как их снижать — без призывов к спаму.
- Практика — только то, что можно выполнить: бесплатные инструменты (GSC, Яндекс Вебмастер, Bing Webmaster, Google Trends, Keyword Planner, Screaming Frog free до 500 URL, PageSpeed Insights, Wayback Machine, Ahrefs Webmaster Tools, Looker Studio) + платные как опция (Ahrefs, Semrush, Serpstat, Keys.so, Topvisor, SpamZilla и т.п.).
- Квизы проверяют **понимание и принятие решений**, а не заучивание; неправильные варианты — правдоподобные ошибки новичка. В `explain` разбирайте и неверные варианты.
- Карточки (`cards`) — для интервального повторения: одно понятие на карточку, ответ короткий.

## Учебный план (порядок и границы уроков — не нарушать, чтобы не дублировать)

**M1 «Фундамент» (Неделя 1)** — 1.1 Как работает поиск: краулинг, индекс, ранжирование; Google/Яндекс/Bing/AI-поиск · 1.2 SERP и интент: типы интента, SERP-фичи, как читать выдачу · 1.3 Факторы ранжирования: контент, ссылки, поведение, техника; E-E-A-T, helpful content, YMYL, апдейты · 1.4 Белое/серое/чёрное SEO, санкции (ручные/алгоритмические), spam policies Google · 1.5 Инструменты: GSC, Яндекс Вебмастер, Bing WMT, GA4/Метрика, Ahrefs/Semrush/Serpstat, Screaming Frog, rank tracker; бесплатный vs платный стек, настройка · 1.6 Бизнес-модели SEO-сайтов, юнит-экономика, что значит «ТОП-10» как цель, дорожная карта курса, как учиться.

**M2 «Ниша и семантика» (Неделя 2)** — 2.1 Выбор ниши (критерии, монетизация, конкуренция, сезонность, YMYL) · 2.2 Сбор семантики (seed, подсказки, Keyword Planner, Wordstat, GSC, Ahrefs, конкуренты) · 2.3 Метрики запросов и оценка сложности (объём, KD, CPC, трафик-потенциал, CTR-кривая, ручной SERP-анализ) · 2.4 Кластеризация и интент (по SERP-пересечению, один запрос — одна страница, каннибализация) · 2.5 Анализ конкурентов (кто реальный конкурент, content/link gap, топ-страницы, слабые места выдачи) · 2.6 Приоритизация и контент-план (quick wins, матрица impact/effort, структура сайта по кластерам, календарь).

**M3 «Покупка сайта и домена» (Неделя 3)** — 3.1 Стратегии: с нуля / expired domain / готовый сайт; политика Google expired domain abuse · 3.2 Где искать: Flippa, Empire Flippers, Telderi, Misterdomain/аукционы (GoDaddy, Dynadot, Namecheap), ExpiredDomains.net, SpamZilla, фильтры · 3.3 Due diligence: ссылочный аудит, Wayback, тематика, спам, индексация, штрафы, трафик, доход, права, технический аудит · 3.4 Оценка стоимости и сделка: мультипликаторы, окупаемость, торг, договор, эскроу, передача · 3.5 Миграция и первые 30 дней после покупки (DNS/хостинг, сохранение URL, 301, GSC, что НЕ менять) · 3.6 Портфель и риски: red flags, диверсификация, разбор 4 сделок-кейсов (иллюстративных), когда отказываться.

**M4 «Техническое SEO» (Неделя 4)** — 4.1 Домен, хостинг, CMS (WordPress и др.), URL, HTTPS · 4.2 Краулинг и индексация: robots.txt, sitemap, noindex, canonical, коды ответов, crawl budget, отчёты GSC · 4.3 Архитектура и внутренняя перелинковка (глубина, хлебные крошки, пагинация, фасетные фильтры, hub/spoke) · 4.4 Скорость, Core Web Vitals (LCP/INP/CLS), mobile-first, рендеринг JS · 4.5 Schema.org и сниппеты (Article, FAQ, Product, Review, Breadcrumb; rich results, OG) · 4.6 Технический аудит от и до: Screaming Frog, редиректы и миграции, дубли, hreflang, шаблон отчёта.

**M5 «Контент и on-page» (Неделя 5)** — 5.1 Принципы SEO-контента: интент, полнота, E-E-A-T, information gain · 5.2 ТЗ/бриф: анализ топа, структура Hn, сущности, LSI/TF-IDF, PAA · 5.3 Написание: заголовок, интро, структура, читабельность, featured snippets, мультимедиа, CTA · 5.4 On-page: title/description/H1/URL/alt/внутренние ссылки/анкоры, шаблон оптимизации · 5.5 Типы страниц и монетизационный контент (обзоры, сравнения, категории, лонгриды, лендинги, affiliate) · 5.6 AI-контент, масштабирование, редполитика; контент-аудит (decay, refresh, merge, prune).

**M6 «Линкбилдинг» (Неделя 6)** — 6.1 Теория ссылок: PageRank, dofollow/nofollow/ugc/sponsored, авторитет, релевантность, анкоры, позиция ссылки · 6.2 Ссылочный профиль конкурентов и расчёт: сколько ссылок нужно под запрос (Ahrefs/бесплатные способы) · 6.3 Оценка доноров и риски: метрики, ловушки, PBN, фермы, сетки, спам-признаки, чек-лист донора · 6.4 Методы получения: гест-посты, outreach (шаблоны писем), digital PR, HARO-аналоги, broken link, linkable assets, ресурсные страницы, крауд, партнёрства · 6.5 Покупные ссылки: биржи (GoGetLinks, Collaborator, Miralinks, PRNEWS.io, Serpzilla и др.), цены, ТЗ, контроль, бюджет, темп, анкор-план · 6.6 Мониторинг и чистка: индексируемость и живучесть ссылок, disavow, ручные санкции, reconsideration, естественность профиля.

**M7 «Запуск до ТОП-10» (Неделя 7)** — 7.1 План запуска 0–90 дней (недельный) · 7.2 Индексация и «песочница»: ускорение, IndexNow, GSC inspection, перелинковка, проблемы · 7.3 Страницы на позициях 11–30: апгрейд контента, CTR, внутренние ссылки, точечные ссылки · 7.4 Трекинг и отчётность: rank tracking, GSC, аналитика, реальные сроки, когда ждать, когда менять · 7.5 Диагностика падений: апдейты, санкции, технические, контентные; плейбук · 7.6 Практикум: три симуляции полного цикла (иллюстративные) и ваш первый проект-план.

**M8 «Масштаб и профессионализм» (Неделя 8)** — 8.1 Topical authority и масштабирование контента: процессы, SOP, фрилансеры, стоимость · 8.2 Монетизация: affiliate, ads (AdSense/Mediavine/РСЯ), лидген, продукты; RPM/EPC/CR · 8.3 Local и e-commerce SEO, мультиязычность (ключевые отличия) · 8.4 SEO в эпоху AI: AI Overviews, ChatGPT/Perplexity, GEO/AEO, упоминания бренда, zero-click · 8.5 Портфель сайтов: финансы, продажа сайта, юр./налоговые основы (общие, без советов), риски · 8.6 Финал: годовой план, типичные ошибки, источники для постоянного обучения, итоговая шпаргалка.
